IoT Intern

InternshipIndoreESP32 · MQTT · Python · Cloud

What you will do

  • Connect ESP32 devices to MQTT brokers and the cloud (AWS IoT Core) for our industrial monitoring products
  • Build Python backends and live dashboards for machine data
  • Set up Wi-Fi provisioning, OTA updates and device security
  • Test devices on the bench and at customer plants, and write the documentation

You should know

  • Basics of C/C++ and Python
  • How Wi-Fi, HTTP and MQTT work; you have sent data from a board to a server at least once
  • Git and GitHub
  • Good to have: AWS IoT, Node-RED or Grafana, Linux on a Raspberry Pi

Embedded Systems Intern

InternshipIndoreEmbedded C · ESP-IDF · STM32 · FreeRTOS

What you will do

  • Write firmware in Embedded C with ESP-IDF and STM32 HAL for our products
  • Bring up sensors and peripherals: ADC, PWM, I2C, SPI, UART, CAN, RS485/Modbus
  • Use FreeRTOS tasks, queues and interrupts in real projects
  • Debug boards with a multimeter, logic analyser and debugger, and help with PCB bring-up

You should know

  • Embedded C: pointers, structs, bit manipulation
  • You have programmed an ESP32, STM32 or Arduino and read a datasheet
  • Basic electronics: Ohm's law, pull-ups, reading a schematic
  • Good to have: FreeRTOS, KiCad, oscilloscope use
