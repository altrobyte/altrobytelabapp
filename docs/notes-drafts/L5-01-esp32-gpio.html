You can wire a button and an LED to an ESP32 and make the button control the LED.

GPIO pins: in or out

  • GPIO means general-purpose input/output: a pin you choose to use as input or output [esp].
  • As OUTPUT the ESP32 drives the pin to 3.3 V or 0 V, for example to light an LED [out].
  • As INPUT it reads whether something outside pulls the pin high or low, for example a button [in].
  • pinMode(pin, OUTPUT) or pinMode(pin, INPUT_PULLUP) in setup() tells the chip which one.

What voltage does an ESP32 output pin give for HIGH?

  1. 5 V
  2. About 3.3 V
  3. 12 V

The ESP32 uses 3.3 V logic; never feed 5 V into its pins.

  • Can every pin be an output? No. GPIO 34 to 39 are input only, and some pins affect booting, so use the pins your kit guide lists.

An LED needs a resistor

  • Current flows from the pin [gpio] through a resistor [res], through the LED [led] to ground [gnd].
  • The resistor limits the current. Without it the LED or the pin can be damaged.
  • The LED's long leg goes towards the pin, the short leg towards GND.

Why is the resistor there?

  1. To limit the current
  2. To make the LED brighter
  3. To store charge

The resistor keeps the current small enough for the LED and the pin.

A button with INPUT_PULLUP

pinMode(4, INPUT_PULLUP);
pinMode(2, OUTPUT);

if (digitalRead(4) == LOW) {   // pressed
  digitalWrite(2, HIGH);
} else {
  digitalWrite(2, LOW);
}

Not pressed: HIGH. Pressed (connected to GND): LOW.

  • Wire the button between GPIO 4 and GND. INPUT_PULLUP turns on a resistor inside the chip that holds the pin high [pull].
  • So the pin reads HIGH when the button is free and LOW when it is pressed. It feels upside down, but it is the usual way.
  • The code reads the button and copies it to the LED [code].

With INPUT_PULLUP, what does digitalRead give while the button is pressed?

  1. HIGH
  2. A random value
  3. LOW

Pressing connects the pin to GND, which pulls it low.

  • Why does my LED flicker when I press once? Buttons bounce for a few milliseconds; a short delay or a debounce check fixes it.

Try it

Tap the part you connect to a pin set as INPUT_PULLUP.
  • The button is the input; the LED and its resistor are on the output pin.

What you learned

  • A GPIO pin is input or output, set with pinMode; the ESP32 uses 3.3 V.
  • An LED always goes with a resistor.
  • With INPUT_PULLUP a pressed button reads LOW.
