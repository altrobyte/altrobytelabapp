You can read and write a small embedded C program: variables, if, loops and functions inside setup and loop.

setup runs once, loop runs forever

  • An ESP32 program has two main parts. setup() runs once when the board powers on [setup]: set pin modes, start Serial.
  • loop() then runs again and again until power is cut [loop]: read sensors, decide, act.
  • A microcontroller never "finishes" a program, like a watchman doing rounds all night.

Where do you put Serial.begin(115200)?

  1. In loop()
  2. In setup()
  3. Outside both, at the end

Starting Serial is needed once, so it goes in setup().

  • Is this real C? It is C++ with the Arduino library; underneath, a main() calls setup once and loop forever.

Variables and if

int temp = readTemp();
if (temp > 40) {
  digitalWrite(FAN, HIGH);
} else {
  digitalWrite(FAN, LOW);
}

temp > 40 is either true or false

  • A variable is a named memory box with a type: int temp holds a whole number [code].
  • if checks a condition [cond]. If it is true, the first block runs; otherwise the else block runs.
  • Here: above 40 the fan turns on, otherwise it turns off. Every smart device is full of decisions like this.

temp is 35. What does the code do?

  1. Turns the fan off
  2. Turns the fan on
  3. Nothing

35 > 40 is false, so the else block runs and writes LOW.

  • Why == and not = in a comparison? = puts a value into a variable; == asks whether two values are equal. Mixing them up is the most common bug.

Loops repeat work

for (int i = 0; i < 3; i++) {
  digitalWrite(LED, HIGH); delay(200);
  digitalWrite(LED, LOW);  delay(200);
}

i = 0, 1, 2 → three blinks

  • A for loop repeats a block a fixed number of times [for].
  • It starts i at 0, runs while i < 3, and adds 1 each time, so the LED blinks three times [count].
  • while (condition) repeats as long as the condition stays true, for example waiting for a button.

How many times does for (int i = 0; i < 5; i++) run?

  1. 4
  2. 6
  3. 5

i takes 0, 1, 2, 3, 4: five values before i < 5 becomes false.

Functions keep code tidy

void blink(int times) {
  for (int i = 0; i < times; i++) { ... }
}
blink(3);   // in loop()
  • A function is a named block you can call again and again [def]. void means it gives nothing back.
  • times is a parameter: you choose the value when you call it, blink(3) [call].
  • Good firmware is many small functions with clear names, not one giant loop.

What does int readTemp() promise?

  1. It takes an int
  2. It gives back an int
  3. It never returns

The type before the name is what the function returns.

What you learned

  • setup() runs once, loop() runs forever.
  • Variables hold values; if/else decides; for and while repeat.
  • Functions are named, reusable blocks with parameters and a return type.
