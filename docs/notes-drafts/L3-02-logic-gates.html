You can say what AND, OR, NOT and XOR do with bits, the way every chip makes its decisions.

AND: both must be on

  • A logic gate takes bits in and gives one bit out. Chips are built from millions of them.
  • AND [and] gives 1 only when input A [a] and input B [b] are both 1.
  • Like a geyser that heats only when the main switch and the geyser switch are both on.

A = 1 and B = 0. What does AND give?

  1. 1
  2. 0
  3. 2

AND needs both inputs to be 1; one of them is 0, so the output is 0.

  • Are these real parts? Yes, as tiny transistor circuits inside the chip; you will also use the same idea in code with the & operator.

OR and NOT

  • OR [or] gives 1 when at least one input is 1. A staircase light that turns on from the switch upstairs or the one downstairs.
  • NOT [not] has one input and flips it: 1 becomes 0, 0 becomes 1.
  • With AND, OR and NOT you can build any decision a chip makes.

A = 0 and B = 1. What does OR give?

  1. 1
  2. 0
  3. It depends on the chip

OR needs only one input to be 1, and B is 1.

XOR: different gives 1

  • XOR gives 1 when the two inputs are different, and 0 when they are the same [table].
  • A table like this, with every input and its output, is called a truth table. Datasheets use them all the time.
  • In firmware, XOR is how you toggle a bit: an LED that was on turns off, and off turns on.

A = 1 and B = 1. What does XOR give?

  1. 1
  2. 2
  3. 0

Both inputs are the same, so XOR gives 0.

Try it

A motor must start only when the guard is closed and the start button is pressed. Tap the gate.
  • Both conditions must be true at once, so it is AND.

What you learned

  • AND needs all inputs 1; OR needs any one; NOT flips.
  • XOR gives 1 when the inputs differ, which toggles a bit.
  • A truth table lists every input and output of a gate.
