You can read and write numbers the way a microcontroller stores them: bits, bytes, binary and hex.

A bit is one switch

  • Inside a chip, every piece of information is a tiny switch that is either off or on, like a ceiling fan switch.
  • Off is written 0 [off], on is written 1 [on]. One such switch is called a bit.
  • On an ESP32, a 1 on a pin means about 3.3 volts and a 0 means about 0 volts.

How many different values can one bit hold?

  1. One
  2. Two
  3. Ten

A bit is either 0 or 1, so it holds exactly two values.

  • Why not use 10 levels like our digits? Two levels are easy to tell apart even with electrical noise, so the chip never confuses them.

Eight bits make a byte

  • Eight bits side by side make one byte [byte]. It is the basic unit the chip stores and sends.
  • Each position has a weight, doubling from right to left: 1, 2, 4, 8 up to 128 [weights].
  • Add the weights where the bit is 1. Here 4 + 1 = 5, so this byte is the number 5.
  • A byte can count from 0 (all zeros) to 255 (all ones), so 256 values.

What number is the byte 00001010?

  1. 5
  2. 8
  3. 10

The 1s sit at weights 8 and 2, and 8 + 2 = 10.

  • Why does a byte stop at 255? All eight weights added together, 128 + 64 + 32 + 16 + 8 + 4 + 2 + 1, make 255.

Hex: a short way to write bytes

  • Long strings of 0s and 1s are hard to read, so engineers split a byte into two halves of four bits [nibbles].
  • Each half is one hex digit: 0 to 9, then A=10, B=11 up to F=15 [hex].
  • So 1111 0001 is written 0xF1. The 0x in front means "this is hex", and you will see it in datasheets and code.

What is 0xFF in decimal?

  1. 255
  2. 15
  3. 100

0xFF is 1111 1111, every bit on, which is 255.

  • Do I have to convert hex in my head? Not at first; the Windows calculator in Programmer mode converts for you. You will learn the common ones by using them.

Try it

Tap the byte that equals 7.
  • 00000111 is 4 + 2 + 1 = 7. The others are 3 and 6.

What you learned

  • A bit is one switch, 0 or 1; on an ESP32 a 1 is about 3.3 V.
  • Eight bits make a byte, which holds 0 to 255.
  • Hex writes each four bits as one digit, so a byte is two hex digits like 0xF1.
