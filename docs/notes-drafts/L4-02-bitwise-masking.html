You can set, clear, toggle and test one bit of a register with bitwise operators, without touching the others.

Shift: make a mask

  • A mask is a number with a 1 only on the bit you care about.
  • 1 is 0000 0001 [one]. The shift operator << slides it left: 1 << 3 puts the 1 at bit 3 [shift].
  • Bits are counted from 0 on the right, so bit 3 has weight 8.

What is 1 << 2 in binary?

  1. 0000 0010
  2. 0000 0100
  3. 0000 0011

The 1 moves two places left, landing on bit 2 (weight 4).

Set with OR, clear with AND NOT

reg |=  (1 << 3);   // set bit 3
reg &= ~(1 << 3);   // clear bit 3
  • To turn one bit on, OR it with the mask [set]. Bits where the mask is 0 stay exactly as they were.
  • To turn one bit off, AND it with the inverted mask [clear]. ~ flips the mask so only bit 3 is 0.
  • This is how you change one pin without disturbing the seven others in the same register.

reg is 0000 0001. After reg |= (1 << 3), what is reg?

  1. 0000 1000
  2. 0000 0001
  3. 0000 1001

OR adds bit 3 and keeps bit 0, giving 0000 1001.

  • Why not just write reg = 8? That would also clear bit 0 and every other bit, switching off pins you did not mean to touch.

Toggle with XOR, test with AND

reg ^= (1 << 3);          // flip bit 3
if (reg & (1 << 3)) { ... }  // is bit 3 on?
  • XOR with the mask flips just that bit [toggle]: on becomes off, off becomes on. A blinking LED in one line.
  • AND with the mask [test] gives a non-zero result only if that bit is 1, so if() can check it.
  • These four lines, set, clear, toggle and test, are used in almost every driver you will read.

Which operator flips a bit each time it runs?

  1. ^ (XOR)
  2. | (OR)
  3. & (AND)

XOR with 1 inverts the bit, so repeating it toggles.

Try it

Tap the line that switches a relay off without touching the other pins.
  • AND with the inverted mask clears only that bit.

What you learned

  • 1 << n makes a mask for bit n.
  • |= sets, &= ~ clears, ^= toggles, & tests.
  • Masks change one bit and leave the rest of the register alone.
