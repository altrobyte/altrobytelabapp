You can explain how a line of code turns a pin on: by setting a bit in a register.

A register is a byte wired to hardware

  • Most memory boxes just hold numbers. A register is a special box whose bits are wired straight to the hardware [reg].
  • In an output register, each bit controls one pin. Make that bit 1 and the pin goes to 3.3 V, and the LED lights [pin].
  • Like the switchboard in your room: each switch is a bit, each light is a pin.

What happens when code sets a bit in an output register to 1?

  1. The program restarts
  2. Its pin goes high (3.3 V)
  3. The byte is saved to flash

Each bit of an output register drives its pin; 1 means high.

  • Where do I find which bit is which pin? In the chip's technical reference manual, the "register map". Datasheets list every register and bit.

digitalWrite is a register write

  • When you write digitalWrite(2, HIGH) [code], you do not touch the register yourself.
  • The Arduino library finds the right register and sets bit 2 for you [lib], and the pin goes high [hw].
  • Knowing this matters when something does not work: you can check the register, not just guess.

Who actually changes the register when you call digitalWrite?

  1. The library code inside the function
  2. The USB cable
  3. VS Code

The library function writes the register; the USB cable only carries your program onto the chip.

Input registers read pins

  • It works the other way too. When a button [button] pulls a pin high, the chip sets that pin's bit in an input register [inreg].
  • digitalRead reads that bit and returns HIGH or LOW.
  • So every sensor reading and every pin you drive comes down to bits in registers.

What does digitalRead actually look at?

  1. The voltage on the USB port
  2. A file on the laptop
  3. A bit in an input register

The pin's level is stored as a bit in an input register, and digitalRead returns it.

What you learned

  • A register is a byte or word whose bits are wired to hardware.
  • Output register bits drive pins; input register bits show what pins see.
  • digitalWrite and digitalRead are library functions that write and read those bits for you.
