You can pick the right data type for a value and explain how it sits in the microcontroller's memory.

Memory is a row of numbered boxes

  • RAM is like a long row of post-office boxes. Each box holds one byte [box].
  • Every box has a number called its address, usually written in hex [address].
  • When your code says temperature = 25, the chip puts 25 in some box and remembers its address.

What does one memory box (address) hold?

  1. One byte
  2. One bit
  3. One whole program

Memory is addressed byte by byte; each address holds 8 bits.

  • Is RAM the same as flash? No. Flash keeps your program even when power is off; RAM holds working values and is wiped at power off.

Data types decide how many boxes

  • A data type tells the compiler how many bytes a value needs and what it means.
  • uint8_t [u8] is one byte, 0 to 255: good for a brightness level or a pin state.
  • int16_t [i16] is two bytes and can be negative: good for a temperature like -5.
  • int32_t and float [i32] are four bytes; float holds decimals like 23.6 °C.

You must store an ADC reading from 0 to 4095. Which type fits?

  1. uint8_t
  2. uint16_t
  3. char

4095 is more than 255, so one byte is too small; uint16_t holds up to 65535.

  • Why not use float for everything? It takes more memory and more time, and small chips have little of both; use whole numbers when you can.

Overflow: when the box is too small

  • A uint8_t holding 255 [full] has every bit on. Add 1 and it wraps around to 0 [wrap], like a car odometer rolling over.
  • This is called overflow. The chip gives no error; your reading is simply wrong.
  • Pick a type big enough for the largest value you will ever store.

A uint8_t counter is at 255 and you add 1. What does it hold?

  1. 256
  2. An error is shown
  3. 0

One byte cannot hold 256, so it wraps to 0 silently.

Try it

Tap the type for a body temperature like 36.8.
  • 36.8 has a decimal point, so it needs float.

What you learned

  • Memory is numbered boxes of one byte each; the number is the address.
  • The data type sets how many bytes a value uses and its range.
  • A value bigger than its type overflows and wraps around without any error.
